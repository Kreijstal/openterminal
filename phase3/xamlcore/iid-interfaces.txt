# Interfaces whose IIDs the DLL needs, named as the pinned SDK IDL qualifies
# them. phase3/scripts/harvest_xaml_iids.py reads the uuid() attributes and
# emits them as constants, because GCC has no __uuidof.
#
# QueryInterface is the only thing these are used for. An IID that is present
# but wrong is worse than one that is absent: the caller asks for an interface
# the object genuinely implements and is told E_NOINTERFACE, which is
# indistinguishable from the class not being implemented at all.

# Boxing. A dependency property's value crosses this ABI as an IInspectable,
# and the only interface a boxed scalar is guaranteed to answer to is
# IPropertyValue. The DLL both produces boxes (through the platform's
# PropertyValue statics, so that a box it hands out is indistinguishable from
# one the caller made) and reads them.

Windows.Foundation.IPropertyValueStatics
