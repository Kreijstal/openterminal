# Windows Terminal dependency snapshot

- Upstream repository: <https://github.com/microsoft/terminal>
- Upstream commit: `fbda436dc654cf551dd196b2667ef95d3e0a7262`
- Generated by: `phase0/scripts/harvest_dependencies.py` and
  `phase0/scripts/harvest_build_surface.py`

This snapshot contains two deterministic inventories:

- `dependency-inventory.json` records declared vcpkg dependencies, NuGet
  references, and top-level vendored dependency entries.
- `build-surface.json` records build inputs, MSBuild properties and imports,
  references, targets, linker inputs, and explicit build-tool mentions.

The data records source declarations only; it does not redistribute package
payloads.
