# Research snapshots

Each committed snapshot lives below a source-project directory and an exact Git
commit. Snapshots must be generated by a checked-in harvester and contain no
redistributed binaries or package payloads.

Cross-project snapshots:

- [`rendering-programs`](rendering-programs/) maps the eight incremental
  renderer exercises to 43 textual files from four exact Microsoft sample
  commits. The source bundle is reproduced under `/tmp`, not committed.
